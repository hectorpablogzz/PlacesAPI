# Places (API Edition)

## What the app does

The app connects to a locally run API that fetches information about places in Monterrey. It has a List View with all the places, and a Detail View with more details about the place. 

## Which API it connects to & endpoint

This app connects to the API in the following GitHub Repo: https://github.com/hectorpablogzz/Monterrey_API

The API must be run locally, and it accesses the following endpoint: http://127.0.0.1:5000/places

## How to run the app

This app was created with Xcode version Version 16.4 (16F6).
The target is iOS 18.5.
It can be run through the iOS Simulator or on a real device.
